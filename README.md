# CODSOFT Cyber Security Internship Tasks

This repository contains the projects completed as part of my CODSOFT Cyber Security Internship.

## Tasks

### Task 2 - Phishing Awareness Program

An interactive web-based phishing awareness training platform designed to educate users about phishing attacks, social engineering techniques, suspicious emails, fake login pages, fraudulent websites, and safe security practices.

#### Features

- Interactive phishing awareness training
- Phishing concepts and attack lifecycle
- Suspicious Email Detector
- Fake Login Page Detector
- Fraudulent Website Detection
- Social Engineering Scenarios
- Real-world phishing case studies
- Practical cybersecurity security tips
- "I Got Phished" incident response guidance
- Final interactive quiz with score
- Module completion and progress tracking
- Responsive dark cybersecurity-themed interface

#### Modules

1. What is Phishing?
2. Suspicious Email Detector
3. Fake Login Page Detector
4. Fraudulent Website Detection
5. Social Engineering Lab
6. Phishing Case Studies
7. Security Tips
8. I Got Phished - What To Do?
9. Final Phishing Awareness Quiz

#### Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Responsive Web Design
